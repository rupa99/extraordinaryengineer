# Essays

Markdown files for essays. Each file becomes a page on the site.

## Format
Each file needs this frontmatter:
```yaml
---
layout: essay
title: Essay Title Here
date: YYYY-MM-DD
---
```
The body is plain markdown. The layout adds drop cap, etched margin lines, and end flourish automatically.

## Naming
Use kebab-case filenames matching the essay topic: `why-startups-ship-broken-things.md`

## Writing rules
- **Never use em dashes (—).** Rewrite instead: use a period, a comma, a colon, or restructure the sentence. This applies to all prose in essays.
- Every line must build on the one before it and be precious. Quality over quantity. Cut any line that could be deleted without weakening the next. No filler, no restating.
- Plain, declarative, second-person voice. No italics, no hype.
